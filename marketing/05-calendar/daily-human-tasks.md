# Daily human rituals, rmux (beyond the scheduled posts)

> What YOU do each day on top of the 🤖 AUTO posts, inside a 30 min, 2 h budget.
> Audience = developers; distribution skews GitHub/HN/Reddit/X + Rust newsletters. Community-led GTM (no paid tier), so replies and issue-triage ARE the marketing.

## Daily (~10-20 min)
- [ ] Reply to comments/DMs/quote-tweets from yesterday on the active platforms (X, LinkedIn).
- [ ] **Triage new GitHub issues** on `Helvesec/rmux`, label, reproduce, or reply. "File an issue and watch it get fixed" is a core promise; a stale issue tracker breaks it.
- [ ] Engage: comment on 3-5 posts from the ICP, Rust devs, Ratatui/TUI builders, agent-infra engineers, tmux power-users.
- [ ] Skim r/rust, r/commandline, HN /new for terminal/agent/tmux threads where a genuine, non-spammy rmux mention adds value.

## On MANUAL post days (block the extra time)
- [ ] **J3 · Fri**, write + post the r/rust architecture value-post; stay in the thread ~2 h to answer. (~35 min write + live replies)
- [ ] **J8 · Wed**, **record the 60s Multi-Agent Orchestration screencast** (the hero asset). Do this in the morning so the 15:00 X post can link it. (~75 min)
- [ ] **J10 · Fri**, run the r/commandline compatibility AMA; keep `.tmux.conf` + a Windows terminal open to screenshot live answers. (~35 min + live)
- [ ] **J13 · Mon**, submit **Show HN** at 09:00, drop the screencast in the first comment, and babysit the thread for the first few hours (this is the launch moment).

## Weekly (spread across the week)
- [ ] Ship at least one visible **release-note / changelog / bugfix** and turn it into a build-in-public post (the preview-stage "bugs get fixed fast" proof).
- [ ] Refresh the **hero repurposing pipeline**: turn the J8 screencast into 1 GIF for the README + 2 standalone tip/quote cards (per `content-strategy.md` repurposing engine).
- [ ] Check the north-star proxies: `crates.io` downloads for `rmux-sdk` + `ratatui-rmux`, GitHub stars added during pushes, HN points, installer runs. Note deltas (do NOT fabricate, R-CITE).
- [ ] Thank + follow up with anyone who filed a good issue, opened a Discussion, or merged a PR.

## Guardrails
- Never announcement-spam Reddit/HN, value-first, engineering-led, link last.
- Honor the fork/upstream scope: public channels (rmux.io, crates.io, Helvesec releases) are **upstream `Helvesec/rmux`**, link there, don't imply ownership.
- Voice = engineer-to-engineer: show the command and the snapshot, not adjectives.
