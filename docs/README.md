# RMUX Documentation

> This is the **`agentik-os/rmux`** fork. The hosted documentation site `rmux.io/docs` belongs to upstream **[`Helvesec/rmux`](https://github.com/Helvesec/rmux)**; it describes upstream and is not a source of truth for this fork's local state. For this checkout, rely on the repository-local guides below plus the in-tree references (`README.md`, `rmux.1`, `spec/`).

It includes [installation guides](https://rmux.io/docs/get-started/), [CLI references](https://rmux.io/docs/cli/), [SDK examples](https://rmux.io/docs/examples/), [terminal automation examples](https://rmux.io/docs/examples/#/terminal-playwright), and [API documentation](https://rmux.io/docs/api/).
